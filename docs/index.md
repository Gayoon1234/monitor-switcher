Monitor Switcher is a Windows desktop application that switches display inputs based on USB device connection events.

## Documentation areas

- [Technical implementation](technical-implementation.md)
- [Road Map](road-map.md)

## Develop the documentation

Install and run the documentation site from the repository root on Windows:

```powershell
cd docs
npm install
npm start
```

Create a production build with:

```powershell
npm run build
```

The generated static site is written to `docs/build/`.
